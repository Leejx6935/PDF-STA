# 给执行 AI 的任务书与阶段提示词

适用项目：三阶液压伺服系统自适应实用预设时间控制。制定日期：2026-10-27。

请先阅读 `01_两个月研究与审核总计划.md` 与 `03_核心文献与检索任务.md`。按顺序执行任务 A—F，不一次性生成整篇论文。当前采用审核者直接调用本机Claude Code、读取本地任务产物的方式交接；获得对应审核结论后再执行依赖它的任务。以下提示词由调度者使用，研究者不需要手工转贴。

## 通用执行约束

1. 你的角色是研究执行者。候选创新是待证问题，文献检索不能被措辞替代。
2. 不编造论文、DOI、公式、实验结果、引用量或仿真输出。检索到摘要就写摘要级；未得到全文就列缺失清单。
3. 区分原文结论、自行复算、数值观察、待证猜想。所有借用引理标注前提与引用位置。
4. 不把“由类似方法可得”作为关键证明。交叉项、未知输入增益项、滤波误差、观测误差和延迟历史都应显式保留。
5. 不覆盖原始 PDF、既有草稿或现有仿真文件。在独立目录保存版本、代码、日志和原始数据。
6. 先查本地和 Zotero 附件。已有解析文本可直接阅读，公式有疑问回到 PDF 原图核查；使用当前环境提供的文档读取工具。
7. 不擅自增加神经网络、故障、未知方向、事件触发等模块。每增加一个假设或模块，说明其必要性并提交审核。
8. 两个月目标是理论、仿真和初稿；液压试验台待研究者与现实导师在理论完成后商量。不能生成虚构实验章节。

## 审核判定表

| 项目 | 通过条件 | 典型退回原因 |
|---|---|---|
| 文献差异 | 最近邻全文支持具体差异 | 把未找到同名论文当创新 |
| 模型 | 状态、量测、单位和工作域一致 | 压差/液压力混用；阀增益暗含未测信号 |
| 实施 | 控制器只有可获得量，反解明确 | 需要未知真实参数、未来峰值、无界导数或当前自身 |
| 理论 | 全部交叉项闭合、量词完整 | 假设有界再证明有界；用小误差替代零误差 |
| 时间 | 整体时间可由已知量设置 | 初值依赖、周期相位、历史刷新没有处理 |
| 精度 | 可计算半径与条件 | 未知常数掩盖初值或增益依赖 |
| 自适应 | 更新律与闭环推导对应 | 仅有投影结构；估计有界冒充参数收敛 |
| 仿真 | 原始数据可追溯，工况公平 | 仅交图片、换对象、删除不利工况 |
| 论文 | 贡献与证据逐项对应 | 猜想写成定理；仿真写成台架实验 |
