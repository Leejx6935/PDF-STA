# 三阶液压伺服系统有限时间控制研究

研究目标：面向三阶液压伺服系统完成一篇理论与验证扎实的英文 SCI 论文，以中科院二区期刊为投稿目标；优先探索预设时间收敛，有限时间控制作为后备路线。投稿目标不代表已确认创新或录用保证。

## 项目目录

- `最终输出/`：审核后的研究计划、文献对照与阶段结果。
- `仿真文件/`：MATLAB / Simulink 模型与控制算法。
- `.research_workspace/tasks/`：逐项任务说明、执行结果与状态。
- `.research_workspace/reviews/`：理论、证据和公式审核记录。
- `.research_workspace/config/`：本地 Claude Code 调度与研究工具接口。

执行结果须经过审核，任务运行成功不等于理论结论成立。当前控制设计沿用位置和两腔压力可测、速度估计的量测条件。

## 本地资料

下载的论文 PDF、全文解析缓存、浏览器证据、运行日志和账户配置不纳入 Git 版本记录。原始全文由本地 Zotero 和研究目录管理。

Claude Code 使用现有 VS Code 扩展提供的执行程序与用户模型配置。调用方式及任务状态见 `.research_workspace/README.md`。
