## 1. 模型与阶次

物理状态取

    x1 = x_p,  x2 = dx_p/dt,  x3 = P1,  x4 = P2

即位置、速度、无杆腔压力、有杆腔压力，共 4 个物理状态。阀芯动态被显式忽略，采用代数关系 x_v = k_u u（式 (4)）。所以本文不是三级阀模型，也没有阀芯位移/阀芯速度两个额外状态；“三阶”来自下面的坐标压缩，而不是来自三级阀。同一作者的参考文献 [35] 处理的是带三级阀的 EHS，但 L13 本身明确丢掉了阀动态，不能把两者混同。

定义 alpha = A2/A1，bar_x3 = x3 - alpha*x4。由 Newton 方程

    P1*A1 - P2*A2 = m*x2_dot + b*x2 + k*x1 + F_L + Delta_F        (1)

可得

    x2_dot = (1/m)*(-k*x1 - b*x2 + A1*bar_x3 - F_L - Delta_F).

压力动态为

    bar_x3_dot/beta_e = k_q*k_u*(h1*g1 + alpha*h2*g2)*u
                        - (A1*h1 + alpha*A2*h2)*x2
                        + (h1*Delta_Q10 - alpha*h2*Delta_Q20),        (6)

其中

    h1 = 1/(V01 + A1*x1),   h2 = 1/(V02 - A2*x1),
    g1 = H(u)*sqrt(Ps - x3) + H(-u)*sqrt(x3),
    g2 = H(u)*sqrt(x4) + H(-u)*sqrt(Ps - x4).

最终写成

    x1_dot = x2,
    x2_dot = p2*bar_x3 + f2 + d2,                                   (7)
    bar_x3_dot/beta_e = p3*u + f3 + d3,                             (7)

    p3 = k_q*k_u*(h1*g1 + alpha*h2*g2),
    f2 = (-k*x1 - b_n*x2 - F_L)/m,
    f3 = -(A1*h1 + alpha*A2*h2)*x2,
    d2 = (-(b - b_n)*x2 - Delta_F)/m,
    d3 = h1*Delta_Q10 - alpha*h2*Delta_Q20.                          (8)

### 1.1 p2 的符号冲突（须原图复核）

式 (8) 的解析文本写作 p2 = -A1/m；但式 (1) 与式 (6) 明确给出 bar_x3 的系数是 +A1/m。按物理方程，p2 应为 +A1/m。若照印刷的负号实现，式 (25) 的前馈项 -p2*bar_x3 与真实对象符号相反，闭环推导中的 p2*alpha_2 消去关系不再成立。该条不是“可选约定”，而是会改变控制方向的实质性符号问题，必须对照原图确认是印刷/OCR 错误还是作者另有定义。

### 1.2 降阶模型不是三个状态的自治 ODE

bar_x3 = x3 - alpha*x4 把两个压力压成一个，但 p3 仍分别依赖 x3、x4（通过 g1、g2），h1、h2 依赖 x1。因此在 (x1,x2,bar_x3) 三个坐标上，p3 不能由 bar_x3 唯一恢复；实现时仍必须测 x3 与 x4。把它称为“三阶系统”在控制设计上可以（p3 视为已知时变函数），但在状态空间意义上不是三个状态的自治系统；原第四阶 x4 的动态与压力域 0<x3,x4<Ps 的正向不变性都没有分析。

### 1.3 已知/未知与扰动结构

- 已知：A1、A2、m、k、F_L、b_n、beta_en（名义值），以及 p2、p3、f2、f3 的函数形式。
- 未知：b、beta_e、Delta_F、Delta_Q10、Delta_Q20、未建模动态。
- 非匹配不确定性：d2 = (-(b-b_n)x2 - Delta_F)/m，进入速度通道。
- 匹配不确定性：d3 = h1*Delta_Q10 - alpha*h2*Delta_Q20，进入压力通道。
- 假设 2 同时对 d_i 及其导数设界：|d_i| <= D1i，|d_i_dot| <= D2i。
- 假设 3 只对 b 与 beta_e 给已知上下界；m、A1、A2 被视为已知常数，这一点对第 2 步的非匹配重构是关键。

### 1.4 量测条件（与本项目合同的差异）

本文控制律实际需要：

- x1：位置，可测；
- x2：速度，直接进入 z2 与 RBFNN 输入，未使用速度观测器；
- x3、x4：两腔压力，用于 bar_x3、p3、f3、g1、g2。

本项目合同是“位置与两腔压力可测、速度估计”。因此 L13 比合同多一个直接可用的速度信号，且没有速度观测器。识别这一差异即可，不改变项目合同；若要把 L13 搬到本项目，必须先把 x2 换成速度估计并重新做第 2 步的重构误差分析。

## 2. 控制链（从虚拟控制到实际阀输入）

### 2.1 第 1 步

    z1 = x1 - x_d,   z1_dot = x2 - x_d_dot.                         (13)
    z2 = x2 - alpha_1.
    V1 = z1^2/2.
    V1_dot = z1*(alpha_1 - x_d_dot) + z1*z2.                        (14)

    alpha_1 = -k1*z1 - k_gamma1*psi(z1) - k_lambda1*|z1|^lambda*sgn(z1) + x_d_hat_dot.   (15)

这里 x_d_hat_dot 由命令滤波器（式 (17)，n=2）对 x_d 求数值一阶导得到；滤波误差记为

    epsilon_1 = x_d_hat_dot - x_d_dot,   |epsilon_1| <= epsilon_1*.   (18)

代入得

    V1_dot = -k1*z1^2 - k_gamma1*z1*psi(z1) - k_lambda1*|z1|^(lambda+1)
             + z1*epsilon_1 + z1*z2.                                (19)

### 2.2 第 2 步（非匹配不确定性的重构）

    z2_dot = p2*bar_x3 + f2 + d2 - alpha_1_dot.                     (20)
    d2 - alpha_1_dot = z2_dot - p2*bar_x3 - f2.                     (21)

用第二个命令滤波器（同样是式 (17)，n=2）对 z2 求数值导数 z2_hat_dot，误差

    epsilon_2 = z2_dot - z2_hat_dot,   |epsilon_2| <= epsilon_2*.   (22)

于是

    d2 - alpha_1_dot = z2_hat_dot - p2*bar_x3 - f2 + epsilon_2.     (23)

    V2 = z2^2/2,
    V2_dot = z2*(p2*alpha_2 + p2*z3 + z2_hat_dot + epsilon_2),
    其中 z3 = bar_x3 - alpha_2.                                     (24)

注意式 (24) 的写法：把 bar_x3 写成 z3 + alpha_2 后，p2*alpha_2 - p2*bar_x3 + p2*z3 = 0，因此它与直接代入的 V2_dot = z2*(z2_hat_dot + epsilon_2) 等价。这一步在代数上自洽，不是漏项。

    alpha_2 = -(1/p2)*( k2*z2 + k_gamma2*psi(z2) + k_lambda2*|z2|^lambda*sgn(z2)
                        + z2_hat_dot - p2*bar_x3 + z1 ).             (25)

代入得

    V2_dot = -k2*z2^2 - k_gamma2*z2*psi(z2) - k_lambda2*|z2|^(lambda+1)
             + z2*epsilon_2 - z1*z2 + p2*z2*z3.                     (26)

关键结构：非匹配项 d2 - alpha_1_dot 不是由神经网络估计，而是由“z2 的滤波导数 + 已知项”代数重构；误差只来自滤波误差 epsilon_2。

### 2.3 第 3 步（匹配不确定性由单个 RBFNN 逼近）

    z3_dot/beta_e = p3*u + f3 + d3 - alpha_2_dot/beta_e.            (27)
    V3 = z3^2/(2*beta_e),
    V3_dot = z3*(p3*u + f3 + d3 - alpha_2_dot/beta_e).              (28)

    d3 - alpha_2_dot/beta_e = w*^T*s(x) + epsilon_3,   |epsilon_3| <= epsilon_3*.   (31)

    u = -(1/p3)*( k3*z3 + k_gamma3*psi(z3) + k_lambda3*|z3|^lambda*sgn(z3)
                  + f3 + w^T*s + p2*z2 ).                           (33)

    V3_dot = -k3*z3^2 - k_gamma3*z3*psi(z3) - k_lambda3*|z3|^(lambda+1)
             + w_tilde^T*s*z3 + z3*epsilon_3 - p2*z2*z3.            (34)

权重自适应：

    w_dot = tau*s*z3 - delta*w.                                     (35)

### 2.4 各动态环节的输入、状态、初始化

| 环节 | 输入 | 状态 | 输出 | 初始化 |
|---|---|---|---|---|
| 滤波器 F1（对 x_d） | x_d | v1,v2（n=2） | x_d_hat_dot = v2 | 论文未给；工程上取 v1(0)=x_d(0), v2(0)=0 |
| 虚拟控制 alpha_1 | z1, x_d_hat_dot | 无 | alpha_1 | 代数 |
| 滤波器 F2（对 z2） | z2 = x2 - alpha_1 | v1,v2（n=2） | z2_hat_dot = v2 | 论文未给；工程上取 v1(0)=z2(0), v2(0)=0 |
| 虚拟控制 alpha_2 | z2, z2_hat_dot, bar_x3, z1 | 无 | alpha_2 | 代数 |
| RBFNN | s = [x1,x2,bar_x3,x_d,x_d_hat_dot]（式 (33) 处写法） | w（N=5） | w^T*s | 论文未给；通常 w(0)=0 |
| 自适应律 | s, z3, w | w | w_dot | 同上 |
| 实际控制 u | z3, f3, w^T*s, p2*z2, p3 | 无 | u | 代数 |

没有观测器；没有输入饱和；没有 anti-windup；没有投影算子。

状态台账：对象 4 个（x1,x2,x3,x4）；控制器 2 个二阶滤波器共 4 个（v1,v2 ×2）；NN 权重 5 个；合计控制器侧 9 个积分状态。z1,z2,z3、alpha_1、alpha_2、psi、s 都是代数量，不能计为独立动态状态。

## 3. 假设—误差—结论表

| 量 | 定义 | 假设/界 | 论文结论 | 时间与依赖 |
|---|---|---|---|---|
| epsilon_1 | x_d_hat_dot - x_d_dot | 由 Remark 6 得 |epsilon_1| <= epsilon_1* | 滤波器固定时间收敛后成立；epsilon_1* 依赖输入信号的 Lipschitz 常数 Delta |
| epsilon_2 | z2_dot - z2_hat_dot | 同上 | |epsilon_2| <= epsilon_2* | 同上；还依赖 z2_dot 的有界性 |
| epsilon_3 | RBFNN 最小逼近误差 | 紧集 Omega 上 | |epsilon_3| <= epsilon_3* | 只在 Omega 内成立；Omega 的不变性未证 |
| w_tilde | w* - w | 假设 ||w_tilde|| <= W | 进入 V | W 未由投影或自适应律证明，见 §5 |
| z1 | x1 - x_d | 无单独假设 | 最终 |z1| <= sqrt(2*V_res) | 仅在 t > T_max 后；V_res 是 V 的残差集 |
| z2 | x2 - alpha_1 | 无单独假设 | 由 V 有界间接有界 | 依赖 alpha_1、滤波状态 |
| z3 | bar_x3 - alpha_2 | 无单独假设 | 由 V 有界间接有界 | 依赖 alpha_2、滤波状态 |
| V | V1+V2+V3+||w_tilde||^2/(2*tau) | 增益满足 r2,r4,r5,r6>0（论文未列） | V_dot <= -r4*V - r5*V^Gamma - r6*V^Lambda + pi4 | T_max 由式 (11) 的 a1,a2,a3 决定，只含增益与 beta_emin；残差半径由 c=pi4 决定，c 含未知 epsilon_i*、W、||w*|| |

**结论性质**：实用固定时间（practical fixed-time），不是精确有限时间，也不是预设时间。跟踪误差进入一个残差集；残差半径由 c 与增益决定，论文没有给出 c 的数值，因此“给定界”并不是可先验计算的米制精度。

## 4. 固定时间主张逐项核查（核心）

### 4.1 T 是否事先给定？

否。论文没有把 T 作为设计输入。式 (11) 的 T_max 是 a1,a2,a3 的函数，而 a1,a2,a3 由增益、beta_emin、tau、delta、varrho、theta 决定；c=pi4 只进入残差集，不进入 T_max 公式。因此：

- T_max 可由设计参数计算（在增益映射修正后），不是“用户指定 T”；
- 不能由用户指定 T 后反解增益；
- 标题中的 “fixed-time” 只表示上界不显含初始状态，不表示可指定时间。

### 4.2 T 是否依赖初值或未知常数？

需要分开说：

1. **T_max 公式**：不含 V(0)，也不含 c、W、epsilon_i*；在这个意义上它是可计算的、形式上初值无关的尾段上界。这是 fixed-time 与 finite-time 的区别所在。
2. **残差半径**：由 c=pi4 决定，c 含 epsilon_1*、epsilon_2*、epsilon_3*、W、||w*||，这些都不是可先验给定的数。因此“最终精度”依赖未知常数，但“T_max 数值”不依赖它们。
3. **T_max 的严格性**：式 (11) 与 c=0 的两段积分完全一致；当 c>0 时，+c 只会减慢下降，论文没有给出“同一 T_max 仍是上界”的证明。所以 T_max 的可计算性不等于它已被证明是 c>0 时到达残差集的时间上界。
4. **W 的循环**：W 是“假设”的权重误差界，论文没有投影算子；若 W 取成依赖 V(0) 的量，则 c、残差、以及“从 t=0 起的时间”都依赖初值，但式 (11) 的 T_max 数值本身仍只由增益决定。
5. **滤波器**：epsilon_i* 只在滤波器自身收敛后成立；滤波器收敛时间依赖被微信号的高阶导数/Lipschitz 常数 Delta，而 Delta 又依赖轨迹与初值。论文没有把滤波器收敛时间与 T_max 相加，也没有给出滤波器收敛时间的数值。

因此：**T_max 的公式可计算且形式上不显含 x0；但“从 t=0 起在 T_max 内进入残差集”没有被严格证明，残差半径依赖未知常数。** 不能把 T_max 当作“已证的可指定时间”。

### 4.3 控制在 T 附近是否有奇异性？

- 控制律中没有 1/(T-t) 或 1/(T_max-t) 这类终端奇异项；psi 是分段 C1 函数，因此在 T 附近没有预设时间方法常见的终端爆破。
- 真正的奇异性不在 T 附近，而在全程：u = -(1/p3)*(...)，p3 = k_q*k_u*(h1*g1 + alpha*h2*g2)。当 x3 -> Ps、x4 -> 0 或 x4 -> Ps、x3 -> 0 时，g1 或 g2 -> 0，p3 -> 0，u 可能无界。论文没有假设 p3 有正下界，也没有讨论 u 的可行性。
- p3 还通过 H(u) 依赖 u 的符号：u>0 与 u<0 对应不同的 p3 分支。可按 B 的符号选分支（B 为式 (33) 括号内各项），B!=0 时解存在；但 B=0 的切换面没有讨论，p3 在压力边界也没有正下界。这是实现层面的正则性缺口，不是 T 附近的奇异性。

### 4.4 T 之后如何定义？

T_max 之后是残差集：V 被 pi4 与增益决定的阈值界住，z1 由 sqrt(2*V_res) 界住。不是 z1=0，也不是精确到达。论文的定理陈述用 “for all t > T_max”，但没有证明残差集的正不变性；只能由比较不等式得到最终有界（ultimate boundedness），不能得到精确归零。

### 4.5 对象、滤波、观测、真实位置各自的时间保证

- 对象状态：没有单独的 x 状态界；只有 V 中 z1,z2,z3 的界。x1 = z1 + x_d 有界；x2 = z2 + alpha_1 有界需 alpha_1 有界；bar_x3 = z3 + alpha_2 有界需 alpha_2 有界，而 alpha_2 含 z2_hat_dot（滤波器状态）。滤波器状态不在 V 中，因此“闭环状态有界”没有被完整证明。
- 滤波器：Remark 6 声称固定时间收敛，但收敛时间的表达式、kappa_i 与 Delta 的关系都没有给出；式 (17) 的幂次索引在解析稿中也不自洽（见 §6.4）。
- 观测器：本文没有观测器，速度直接用 x2。
- 真实位置误差：只有 z1 的残差界，且该界由 V 的界推出，量纲上把 m^2、(m/s)^2、Pa 混在一起（见 §6.5），因此这个数值界只是形式上的。

**总判断**：本文是“实用固定时间 + 残差集”的结果；T 不可由用户指定；T_max 可由增益计算，但其作为 c>0 时上界的严格性未证；真实位置没有精确有限时间保证。不能把标题或摘要中的 “fixed-time” 当作“预设时间”或“精确到达”的证据。

## 5. 单个神经网络与非匹配不确定性重构

### 5.1 结构

- 非匹配项 d2 - alpha_1_dot：由式 (23) 代数重构，使用 z2 的滤波导数、bar_x3、f2、p2。没有神经网络。
- 匹配项 d3 - alpha_2_dot/beta_e：由单个 RBFNN 逼近（式 (31)），N=5，输入在式 (31) 处写为 [x1,x2,bar_x3]，在式 (33) 处又写为 [x1,x2,bar_x3,x_d,x_d_hat_dot]。两处输入维数不一致，这是原文的内部不一致，不是我的改写。
- 权重自适应式 (35) 只有 tau*s*z3 - delta*w，没有投影、没有死区、没有归一化。

### 5.2 这个结构的实际优点

- 避免了对 alpha_1 的解析求导，也避免了为每个虚拟控制配一个神经网络；相比传统多 NN 反步，参数少、结构简单。
- 非匹配项的重构是“精确到滤波误差”的代数关系，不需要 NN 逼近，因此不存在非匹配项的逼近域问题；这是本文最可迁移的想法。
- 单 NN 只承担匹配项，维数低（N=5），工程上容易实现。

### 5.3 代价与未证条件

- 重构依赖 z2_dot 的数值导数。z2 = x2 - alpha_1，含速度 x2；若速度由观测器估计，则 z2_dot 的误差会叠加观测器误差与微分噪声，本文没有分析。
- 重构依赖 p2 已知（即 m、A1 已知）与 f2 已知（b_n、k、F_L 已知）。若 m 或 A1 有参数误差，式 (23) 的“非匹配项”会含 (p2_true - p2_nominal)*bar_x3 的偏差，且该偏差不被 NN 补偿。
- 单 NN 的逼近对象 d3 - alpha_2_dot/beta_e 含 alpha_2_dot；alpha_2 含 z2_hat_dot，因此逼近对象依赖滤波器状态与 x2_dot，不完全是 [x1,x2,bar_x3] 的静态函数。论文用紧集上的万能逼近一笔带过，没有证明该函数在 Omega 上的连续性/有界性，也没有证明轨迹在收敛前不离开 Omega。
- 自适应律没有投影，||w_tilde|| <= W 是假设而不是结论；这与 §4.2 的 W 循环问题相连。

## 6. 分段函数正则性、逼近域、余项与真实位置误差

### 6.1 psi 的正确读法

式 (16) 的解析文本把多项式段写成 c_i1*z_i + c_i2*z_i^2；但：

- Remark 4 明确写的是 c_1i*z_i + c_2i*z_i^3；
- Case 2 的推导写的是 -k_gamma_i*(c_i1*z_i^2 + c_i2*z_i^4)，这对应 z*psi = c1*z^2 + c2*z^4，即 psi 的多项式段必须是三次。

因此正确读法是

    psi(z) = |z|^gamma*sgn(z),                    |z| >= xi
    psi(z) = c1*z + c2*z^3,                       |z| < xi
    c1 = ((3-gamma)/2)*xi^(gamma-1),
    c2 = ((gamma-1)/2)*xi^(gamma-3).

验证：在 z=xi 处，c1*xi + c2*xi^3 = xi^gamma；在 z=-xi 处为 -xi^gamma；导数 c1 + 3*c2*xi^2 = gamma*xi^(gamma-1)，与幂函数段导数相接。因此 psi 是奇函数且 C1。若照印刷的 z^2 实现，psi(-xi) = (gamma-2)*xi^gamma != -xi^gamma，在负侧不连续，且 z*psi 与 Case 2 的 z^4 项不匹配。结论：式 (16) 的 “z_i^2” 是 OCR/印刷问题，原文应为三次；但仍须原图确认。

### 6.2 c1+c2>0 的隐含参数条件

    c1 + c2 = [(3-gamma)*xi^2 + (gamma-1)] / (2*xi^(3-gamma)).

因为 0<xi<=1，分母为正，所以 c1+c2>0 等价于

    xi^2 > (1-gamma)/(3-gamma).

对 gamma=1/3（本文仿真取值），阈值是 xi > 0.5。论文只写 0<xi<=1 并声称 c1+c2>0，没有给出这个下界；Remark 4 又说“选足够小的 xi”让幂函数项占主导，这与 c1+c2>0 的要求方向相反。若 xi 取得过小，Case 2/3 中的多项式阻尼项变号，证明中的放缩不成立。论文没有给出仿真用的 xi 数值，无法核对其是否满足该条件。

### 6.3 逼近域与余项

- RBFNN 的万能逼近只在紧集 Omega 上成立；论文没有定义 Omega，也没有证明闭环轨迹在收敛前留在 Omega 内。
- epsilon_3* 是未知常数；残差 c 含 epsilon_3*^2，因此残差半径不可先验计算。
- 输入向量在式 (31) 与式 (33) 处不一致（3 个 vs 5 个信号）；若按 5 个输入实现，中心矩阵是 5×5，第一、二、四、五行中心在 [-0.4,0.4]，第三行在 [-16,16]。第三行对应 bar_x3，说明作者把压力按 MPa 缩放；但模型 p3、f3 使用 SI 的 Pa。NN 输入的单位没有在文中说明，这是复现时的实际歧义。

### 6.4 命令滤波器的幂次索引

式 (17) 的 r_0i、r_inf,i 递推在解析稿中为

    r_0i = 1 - (n-i)*d0,   d0 = -1,
    r_inf,i = 1 - (n-i)*d_inf,   0 < d_inf < 1/(n-1).

对 n=2，i=1,2,3：r_01=2, r_02=1, r_03=0；l2 的指数 r_03/r_02 = 0，出现零指数。这显然不能直接实现。合理的读法应是递推从 r_{n+1}=1 出发、指数为 r_{i+1}/r_i，使 l1、l2 的指数都落在 (0,1) 或 (1,∞) 的常规范围；但解析稿的公式不足以唯一恢复。该滤波器是全文的核心部件，幂次设计不能靠猜。此项必须对照原图或参考文献 [49] 复核，当前列为未复现项。

### 6.5 真实位置误差界的量纲问题

V = V1 + V2 + V3 + ||w_tilde||^2/(2*tau)，其中

- V1 = z1^2/2 的量纲是 m^2；
- V2 = z2^2/2 的量纲是 (m/s)^2；
- V3 = z3^2/(2*beta_e) 的量纲是 Pa（因为 z3 是 Pa，beta_e 是 Pa）。

三者直接相加在量纲上不成立。由此得到的 V^Gamma、r1、r2、r3 以及 |z1| <= sqrt(2*V_res) 都只是形式不等式；若要严格化，需要对每个通道引入带量纲的归一化权重（例如 V1/z1_scale^2 等），并重新定义所有增益条件。论文没有做这一步。这也是“真实位置误差界”不能直接当作米制数值使用的原因之一。

## 7. 实际优点

1. 滤波器不直接作用于虚拟控制律，而作用于 z2 = x2 - alpha_1，从而把“避免 EOC”和“重构非匹配不确定性”合并为一个环节。这个思路清晰，且第 2 步的代数重构在无噪声、p2/f2 已知时是成立的。
2. 单个 RBFNN 只逼近匹配项，非匹配项用确定性重构；相比多 NN 方案，参数少、失效点少。
3. psi 的分段三次多项式在正确取值下是 C1 的，确实避免了 |z|^gamma 在 z=0 处的导数奇异；这是对固定时间反步中经典奇异性的合理工程处理。
4. Lemma 1 在 V_dot 中保留线性项 -a3*V，比常见的 -a1*V^b1 - a2*V^b2 + c 更精细；我独立积分核对，式 (11) 的两段结构是对的。
5. 仿真对比覆盖了有限时间、传统多 NN、经典幂函数、以及三篇最新方法（C5–C7），对比维度较完整；但这些都是作者自报工况，不是本项目复现结果。

## 8. 适用边界（不能直接搬用的条件）

- 速度 x2 直接可测；没有速度观测器。
- 两腔压力 x3、x4 都必须可测，且要满足 0 < x3,x4 < Ps，p3 要有正下界；论文没有给这个下界。
- 阀动态被忽略（x_v = k_u u）；不是三级阀模型。
- 没有输入饱和、没有 anti-windup、没有噪声定理；结论中明确把噪声留作 future work。
- 参数 m、A1、A2 被视为已知；只有 b、beta_e 有界假设。
- 增益必须满足 r2,r4,r5,r6>0（尤其 2*k2 > 1 + r1），论文没有在定理中列出；仿真增益按解析稿数值不满足（见 §9）。
- psi 的 xi 必须满足 xi^2 > (1-gamma)/(3-gamma)，论文没有列。
- RBFNN 只在紧集 Omega 上有效；Omega 的不变性未证。
- 结论是实用固定时间 + 残差集，不是精确有限时间，也不是预设时间。

## 9. 仿真与可复现性核对

### 9.1 表 1 参数

Ps=21 MPa，A1=1.96e-3 m^2，A2=1.65e-3 m^2，b=30 N/(m/s)，m=20 kg，W_v=(pi/4)e-3，C_d=0.62，beta_e=1700 MPa，V10=V20=5e-6 m^3，rho=850 kg/m^3，行程 0.5 m。

### 9.2 物理一致性检查：V2 在初始位置为负

V2 = V20 - A2*x1。取 x1=0.32 m（论文初值）：

    A2*x1 = 1.65e-3 * 0.32 = 5.28e-4 m^3,
    V2 = 5e-6 - 5.28e-4 = -5.23e-4 m^3 < 0.

事实上 V2>0 只对 x1 < V20/A2 = 5e-6/1.65e-3 ≈ 3.03e-3 m 成立，而参考轨迹在 0.25±0.02 m。按表 1 的 V20=5e-6 m^3，仿真在整个工作区间都处于负腔体积，h2<0、sqrt(P2) 等项失去物理意义。结论：表 1 的初始体积数值（或单位/指数）与仿真初值、参考轨迹不相容；按印刷值无法复现论文的仿真。该条与 OCR 无关，是表内数值与初值/行程的直接冲突，需作者原表或代码确认。

### 9.3 缺失参数

表 1 没有给出：k_u（阀芯位移增益）、k（弹性系数）、F_L（已知常值力）、psi 的 xi_i、Lemma 1 的 theta、式 (43) 的 varrho、W、epsilon_i*。因此 p3、f2、psi、T_max 都无法按论文数值复算。仿真部分也没有给出时间步长、求解器、噪声设置。

### 9.4 增益与定理条件的数值核对

按解析稿所载（该行 OCR 有明显重复下标，数值本身待原图确认）：

    k1=1000, k2=0.1, k3=12000;
    k_gamma1=0.2, k_gamma2=0.015, k_gamma3=12;
    k_lambda1=1000, k_lambda2=0.1, k_lambda3=1000;
    gamma=1/3, lambda=8/5, tau=30, delta=4.

于是 Gamma=(gamma+1)/2=2/3，Lambda=(lambda+1)/2=1.3，

    r1 = min{2^(2/3)*0.2, 2^(2/3)*0.015, (2*beta_emin)^(2/3)*12}
       ≈ min{0.317, 0.0238, 很大} = 0.0238.

    r2 = min{2*k1 - 1 - r1, 2*k2 - 1 - r1, beta_emin*(2*k3-1) - r1}
       = min{1998.98, 0.2 - 1 - 0.0238, 很大}
       = -0.8238 < 0.

第二项即使令 r1=0 也是 2*0.1-1 = -0.8 < 0。也就是说，按论文自己列出的 k2=0.1，定理所需的 r2>0 不成立；而 r2 是式 (40) 中线性衰减系数的基础，r4=min{r2, delta*(1-varrho)} 也随之为负。Lemma 1 不能应用，式 (11) 的 T_max 不能由这组增益得到（对数内会出现负值）。

这不是说仿真一定不稳定（充分条件保守时仿真仍可能收敛），而是说：**论文的仿真不能作为其定理成立的经验验证**；二者之间存在参数层面的不一致。该结论以解析稿的 k2=0.1 为前提；若原图为 k2=10 之类，则需重算，故列为待原图核对项。

### 9.5 T_max 的量级

即使忽略 r2<0，把 r4 取为 delta*(1-varrho)（例如 varrho=0.5，r4=2），按正确映射 a1=r5, a2=r6, a3=r4 估算：

    T_max ≈ 1/(r4*(1-Gamma))*ln(1+r4/r5) + 1/(r4*(Lambda-1))*ln(1+r4/r6)
          ≈ 1/(2/3)*ln(1+2/0.0238) + 1/(2*0.3)*ln(1+2/0.246)
          ≈ 1.5*4.44 + 1.67*2.21 ≈ 10.4 s.

而仿真声称 C1 在 0.1 s 内收敛（第 5.2 节）。两者不矛盾（上界可以很保守），但说明 T_max 不是“0.1 s 的设计时间”，也不能用来反推用户指定的 T。T_max 是可由增益计算的，但仿真精度不是它的推论。

### 9.6 其他仿真不一致

- d3 的单位：式 (7) 中 bar_x3_dot/beta_e = p3*u + f3 + d3，故 d3 的量纲是 1/s；论文在仿真段写 “MPa/s”。按 0.2 L/min 的泄漏系数换算，d3 的数值量级与 1/s 一致，但标签错误。
- RBFNN 中心第三行取 ±16，暗示 bar_x3 以 MPa 为单位；模型其余部分用 Pa。若直接把 Pa 送入 NN，中心与宽度完全失配。
- 初始状态只给 [x1,x2,x3]=[0.32,0,0]，未给 x4；按 bar_x3=x3-alpha*x4，若 x4=0 则 bar_x3=0，但 V2 问题仍然存在。
- 仿真无噪声、无饱和；结论承认噪声是 future work。因此论文没有“噪声下仍有定理保证”的结论。Remark 6 只给滤波器级的噪声误差上界 L_i*Delta^((i-1)/n)*epsilon^((n-i+1)/n)，没有传播到跟踪误差；仿真也未注入噪声。

## 10. 对本项目的含义

1. **定位**：L13 是 2026 年的最新竞争工作，属于“实用固定时间 + 命令滤波 + 单 NN”的路线；它是 fixed-time 基线，不是 preset-time 基线。不能因为标题含 fixed-time 就把它归入“可指定时间”的方法。
2. **可迁移的想法**：用 z2 的滤波导数代数重构 d2 - alpha_1_dot，把非匹配不确定性从 NN 中剥离；单 NN 只逼近匹配项。这与本项目“单网络 vs 非匹配不确定性重构”的问题直接相关，值得作为结构对照。
3. **不可直接迁移的条件**：速度直接可测、p3 正下界、无饱和、无噪声、m/A1 已知、psi 的 xi 条件、NN 紧集。若搬到本项目，至少要先解决速度估计进入 z2_dot 的误差传播，以及输入饱和下的 p3/u 可行性。
4. **引用纪律**：只能引用经核对的部分（模型式 (1)–(7)、第 1/2 步的代数重构、psi 的三次 C1 读法、Lemma 1 的结构）；不得引用其 T_max 数值、仿真精度、或“irrespective of initial conditions”作为已证结论。其定理证明存在映射错误与未证条件，详见 proof_reconstruction.md。
5. **与 L03 的区别**：L03 是指数/FTUB，且观测器证明有额外假设；L13 是实用固定时间，时间上界形式更接近 fixed-time，但同样没有预设时间、没有饱和/噪声定理。两者都不能作为“精确有限时间”基线。
