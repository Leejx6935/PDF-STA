## 3. vdot 链独立重推（决定结论是否正确的那一步）

### 3.1 i=0

zdot0 = x1 - x_d = z1 + x1^c - x_d。插入 alpha0 = x_d - k0*z0 - c0*v0^(2p-1)：
zdot0 = z1 + (x1^c - alpha0) - k0*z0 - c0*v0^(2p-1)。
xidot0 = -k0*xi0 + xi1 + (x1^c - alpha0) - l0*xi0^(2p-1)。
相减，**(x1^c - alpha0) 精确抵消**：
vdot0 = v1 - k0*v0 - c0*v0^(2p-1) + l0*xi0^(2p-1)。与 (28) 方括号一致。**通过。**

关键观察：抵消用的不是"滤波误差的界"，而是**在线可算的滤波误差本身**；因此补偿是精确的，phi 只出现在后面 xi_i*(x_{i+1}^c - alpha_i) 的 Young 界 (43) 里。

### 3.2 i=1

zdot1 = x2 - x1^cdot = z2 + x2^c - x1^cdot。以 alpha1 = x1^cdot - k1*z1 - c1*v1^(2p-1) - z0 代入得 -x1^cdot + alpha1 = -k1*z1 - c1*v1^(2p-1) - z0，故
vdot1 = v2 - k1*v1 - c1*v1^(2p-1) - v0 + l1*xi1^(2p-1)。与 (32) 一致。**通过。**

### 3.3 i=2

zdot2 = x3 - th1*x2 + D1 - x2^cdot = z3 + x3^c - th1*x2 + D1 - x2^cdot。
alpha2 = x2^cdot - k2*z2 + th1hat*x2 - c2*v2^(2p-1) - z1 - D1hat 代入：
vdot2 = v3 - k2*v2 - c2*v2^(2p-1) - v1 - th1tilde*x2 + D1tilde + l2*xi2^(2p-1)。
与 (36) 方括号一致（其中 th1tilde=th1-th1hat、D1tilde=D1-D1hat）。**通过。**

### 3.4 i=3（含输入反解的那一步，最易错）

zdot3 = g1*f*[u-pi] - th2*x2 - th3*x3 + D2 - x3^cdot。
先注意一个恒等式：由 (38)，**f*u = bracket/g1hat**，bracket := -k3*z3 - z2 + th2hat*x2 + th3hat*x3 - D2hat - c3*v3^(2p-1) + x3^cdot。
于是 g1*f*u = (g1/g1hat)*bracket = bracket + (g1-g1hat)*bracket/g1hat = bracket + g1tilde*f*u。
（因为 bracket/g1hat = f*u。）这正是 (40) 中 g1tilde*f*u*v3 的来源，**不是近似**。我原以为这里有 g1/g1hat≈1 的省略，复算后确认是精确等式。**通过。**

vdot3 = bracket - g1*f*pi - th2*x2 - th3*x3 + D2 - x3^cdot + g1tilde*f*u + k3*xi3 + xi2 + l3*xi3^(2p-1)
      = -k3*v3 - v2 - c3*v3^(2p-1) + l3*xi3^(2p-1) - th2tilde*x2 - th3tilde*x3 + D2tilde + g1tilde*f*u - g1*f*pi。
与 (40) 一致（方括号内各项符号逐一核对无误）。**通过。**

## 4. 两个辅助不等式的核对

- (41)：|g1*f*pi| <= D = g1max*f_max*pi0，故 -g1*f*pi*v3 <= D|v3| <= (D/2)v3^2 + D/2。**通过**（用 |v| <= (v^2+1)/2）。
- (43)：|xi_i|*|x_{i+1}^c - alpha_i| <= xi_i^2/2 + phi_i^2/2。**通过**，但注意 i=0,1,2 才有此项，i=3 没有——(44) 与 (46) 对 xi3 保留 -k3*xi3^2 而其余用 -(k_i-1/2)，**这一点是对的**。

## 5. 分数幂项与自适应律系数：两处实质偏差

### 5.1 (26) 自身是对的（易被误判）

l_i*v_i*xi_i^(2p-1) <= (l_i/(2p))|v_i|^(2p) + [l_i - l_i/(2p)]|xi_i|^(2p)。
即 Lemma 2 取 b1=1, b2=2p-1, b3=1 时 xi 项系数 = (2p-1)/(2p) = 1 - 1/(2p)，与原文"l_i|xi|^(2p) - (l_i/2p)|xi|^(2p)"完全相同。再与 xidot_i 里的 -l_i*xi_i^(2p) 合并，净得 -l_i/(2p)*xi_i^(2p)，与 (32)(46) 一致。**此项通过，原文写法怪但正确。**

### 5.2 Delta_tilde / theta_tilde / g_tilde 的负定系数被多算（D2）

以 D1 为例，D1hatdot = mu1*v2 - sigma1*D1hat，D1tilde = D1 - D1hat，故
(1/mu1)*D1tilde*D1tildedot = -D1tilde*v2 + (1/mu1)*D1tilde*D1dot + (sigma1/mu1)*D1tilde*D1hat。
第一项与 Vdot 中的 +D1tilde*v2 抵消。余下用 D1hat = D1 - D1tilde 与两个 Young：
(sigma1/mu1)*D1tilde*D1hat <= -(sigma1/(2mu1))*D1tilde^2 + (sigma1/(2mu1))*D1^2，
(1/mu1)*D1tilde*D1dot <= (sigma1/(4mu1))*D1tilde^2 + (1/(sigma1*mu1))*D1dot^2。
**合计只能是 -(sigma1/(4mu1))*D1tilde^2**，残差 (sigma1/(2mu1))*D1^2 + D1dot^2/(sigma1*mu1)。

而 (44) 同时列出 -sigma1/(2mu1)*D1tilde^2 与 -sigma1/(4mu1)*D1tilde^2（合计 3/4），比可推导值多 3 倍；theta、g 项同样多算（1/2 + 1/4）。原文档残差写作 (sigma1/mu1)*[D1dot/sigma1 + D1]^2，把交叉项 2*D1dot*D1/mu1 也当成正残差，与上述不同的拆法。
**结论：结构（-alpha*V3 型）仍可成立，但 (47) 的 alpha 必须加约束 alpha <= sigma1/2（Delta 项）而不是 2*sigma1；printed alpha 不成立。**这一条可修，不影响"实用有限时间"的定性结论。

### 5.3 论文自己的增益使 beta 为负（D3，最严重）

(47)：beta = min{ 2^p*(c_i - l_i/(2p)), 2^p*l_i/(2p), sigma1/2^p }。
代入论文 4.2 给定值 c_i=0.5（i=1,2,3）、l_i=1、p=99/101（2p=1.9604）：
- l_i/(2p) = 0.5101
- c_i - l_i/(2p) = **-0.0101 < 0**
- i=0：c0=0.1，l0 未给（若 l0=1，则 0.1-0.5101 = -0.4101）

于是 (46) 中的 -sum(c_i - l_i/(2p))*v_i^(2p) 实为正项（destabilizing），beta <= 0，(46) 的 -beta*V3^p 不能成立，**T1 (49) 的两个 ln 自变量出现 beta<=0，时间界无定义**。
充分条件本应是 **l_i < 2*p*c_i = 0.9802**（或 c_i > 0.5101）。论文取 l_i=1、c_i=0.5，恰好跨过阈值 0.9802。
可修方式：(a) 取 l_i<=0.9 或 c_i>=0.6；(b) 在 Lemma 2 里保留自由 b3 使 v 项系数降为 b3/(2p)（代价是 xi 项系数放大 b3^(-1/(2p-1))）；(c) 把正项 |v|^(2p) <= 1 + v^2 并入 -k_i*v_i^2 与 b。
注意：仿真仍会收敛，因为 k_i=500 的线性项主导，1e-2 量级的分数幂项被淹没——**这正说明报告中的仿真并没有检验到有限时间机制**。

## 6. 时间界 (49)/(15) 的可计算性

先用标量方程核对 Lemma 1 的第二支：Vdot = -alpha*V - beta*V^gamma + b，令 W=V^(1-gamma)，在 V >= (b/(eta*beta))^(1/gamma) 区域有 Wdot <= -(1-gamma)*alpha*W - (1-gamma)*(1-eta)*beta，解得
T <= 1/(alpha*(1-gamma)) * ln[ (alpha*V(0)^(1-gamma) + (1-eta)*beta) / ((1-eta)*beta) ]，
把 (1-eta) 记作 eta 即 (15) 的第二支。**公式形式正确。**（第一支对应把 alpha 折价的另一种拆法，与 Yu-Shi-Zhao 型引理一致，我不重复推导。）

但 (49) 作为"可计算时间界"不成立：
1. **T_c 无公式**。Lemma 4 只说"存在足够大的 wn 使 |x^c-alpha|<=phi on [0,T_c)"，T_c 与 phi 都没给表达式；(49) 直接把 T_c 加到界上。
2. **phi_i 无数值**，(48)(50) 的半径与 (49) 都依赖它。
3. **sigma1 未给数值**，而 alpha=2*min{...,sigma1} 几乎总被 sigma1 决定；beta 也含 sigma1。故 alpha、beta、T1 全部无法代入。
4. **V3(0) 不可算**：D1hat(0)、D2hat(0) 未给；theta/g1 的允许区间未给（b 里含 theta_imax、g1max）。
5. **eta 是自由参数**，T1 随 eta 变化，最优 eta 未讨论；且 T1 随 V3(0) 对数增长——**依赖初值，不是预设时间**。
6. 由 D3，按论文数值 beta<=0，(49) 直接失效。

**判定：不存在可事先指定、且已证明成立的 T；论文给出的是"存在有限 T1"的表达式骨架，数值化所需的三类量（T_c、phi_i、sigma1 及区间界）均缺失。对"T 是否事先给定"的回答：否；"是否依赖初值"：是（对数依赖）；"T 附近是否奇异"：见第 8 节 D7；"T 之后如何定义"：(48)(50) 的残差集，UUB；"各环节时间保证"：对象/滤波/观测/真实位置四者中，只有"滤波跟踪误差 v_i、xi_i"有界，对象状态与真实位置误差无独立时间保证。

## 7. 真实位置误差与定理误差不是同一个量（D5，我的补充推导）

定理给出 |z1|<=|v1|+|xi1|。而 z1 = x1 - x1^c，x1^c 是 alpha0 的滤波输出。真实误差
e1 := x1 - x_d = z1 + (x1^c - alpha0) + (alpha0 - x_d) = z1 + (x1^c - alpha0) - k0*z0 - c0*v0^(2p-1)。
由 V3 的残差 R 得 |z1|<=2*sqrt(2R)、|z0|=|v0+xi0|<=2*sqrt(2R)、|v0|<=sqrt(2R)，故
**|e1| <= 2*sqrt(2R) + phi0 + 2*k0*sqrt(2R) + c0*(2R)^((2p-1)/2)**。
即真实位置误差界比 (50) 多出 k0*z0 项（k0=20，放大 20 倍）、滤波偏置 phi0 与 c0*v0^0.96 项。
论文没有写这一步。结论方向不变（仍是有界），但**"位置跟踪误差" 的定量界不能直接引用 (48)(50)**；若审稿人追问，这一步必须补，且会显著放松精度声明。另外 e1 = zdot0，参考不连续时 e1 跳变，任何"逐点精确跟踪"的表述都不成立。

## 8. 未闭合/待证步骤

- **D1**：(36) 首项印为 +sum k_i*v_i^2，数学上必须为负（否则 Vdot 不能负定；且 (40)(44) 均为负）。判为排版/OCR 错误，待原图核对。
- **D2/D3**：见 §5，系数与 beta 符号问题；可修，但 printed 数值不自洽。
- **D6 输入反解正则性**：u 隐含在 f(PL,u)=sqrt(Ps-sign(u)PL) 内。需按 sign(u) 分两支求解并检验分支自洽；u=0 时死区使 x_v=0 但 f 仍有定义（sign(0) 取 +1），需约定。论文未讨论。控制增益下界 g1hat*f >= g1min*f_min 中 f_min 未量化，Assumption 2 只有"far away from zero"。
- **D7 虚拟控制导数条件**：三条虚拟控制都含 v^(2p-1)，2p-1=0.96 in (0,1)，**在 v=0 处导数无界（Hölder 而非 Lipschitz）**。二阶滤波器要给出**一致**的 phi，需要 sup|alphadot| 有界；v 过零瞬间该条件失效。论文用 Lemma 4 一句"存在足够大 wn"带过，未处理该奇异性。加之滤波器状态不在 V3 中，滤波器有界性只能由 phi 界间接得到，存在"要 phi 小需 alphadot 有界、要 alphadot 有界需 v 有界、v 有界又依赖含 phi 的 b"的弱循环。可用 ISS/小增益补，但文中未做，标为待证。
- **D8**：复现缺 sigma1、eps、l0、D1hat(0)、D2hat(0)、参数区间、死区界、扰动界、x(0)、采样与求解器。
- **D9**：引言"死区补偿项纳入最终控制律"与 (38) 不符，实际只有 (41) 的鲁棒阻尼。

## 9. 对优先问题的直接回答

1. **滤波补偿变量如何进入真实误差**：xi_i 的动力学里放入可算的 (x_{i+1}^c - alpha_i)，与 zdot_i 中同项精确相消，使 vdot_i 成为 v_{i±1} 的串级；v_i=z_i-xi_i 才是被 V3 界定的量。真实位置误差 e1 还要加上 (x1^c-alpha0) 与 -k0*z0-c0*v0^(2p-1)，见 §7。
2. **有限时间结论对应哪个误差**：对应 v_i、xi_i（进而 z_i=x_i-x_i^c）；不是 x1-x_d，也不是参数误差（参数只 UUB）。
3. **虚拟控制导数条件**：不需要 x_d 的导数（这是真的，全文无 x_ddot）；但需要 x_i^cdot，取自滤波器状态；滤波器的输入 alpha_i 含分数幂，v 过零时导数无界，一致性未证（D7）。
4. **死区已知程度**：断点未知但上下界已知；左右斜率相等且为常数 k_i（强假设）；只用 pi0 与 f_max。
5. **有无可计算时间界**：**未建立**（T_c、phi_i、sigma1/区间缺失，beta 符号错，且依赖 V3(0)、eta）。
