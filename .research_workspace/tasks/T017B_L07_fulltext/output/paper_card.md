## 0. 一句话结论（面向本次优先问题）

本文是**实用有限时间（practical finite-time）**结论：Lyapunov 不等式 Vdot3 <= -alpha*V3 - beta*V3^p + b，残差集由 b 决定；**不是精确有限时间，没有预设时间**。被证明收敛的误差是**补偿后的滤波跟踪误差 v_i = z_i - xi_i** 与补偿信号 xi_i，其中 z_i = x_i - x_i^c（i>=1，x_i^c 是虚拟控制经二阶命令滤波器的输出），再由 |z_1| <= |v_1| + |xi_1| 得界。**真实位置误差 x1 - x_d 没有被直接界定**（它等于 z0 的导数），需额外一步，见 proof_reconstruction 第 7 节。时间界 (49) 形式可写，但含未量化的 T_c 与 phi_i，依赖 V3(0) 与自由参数 eta；且按论文自己给的增益算，beta 为负，(49) 无定义。故**可计算时间界：未建立**。死区不是逆补偿，只在 Vdot3 中用 (D/2)v3^2 + D/2 做鲁棒阻尼；断点未知但有已知界、左右斜率相等是硬模型限制。速度 x2 在控制律与四条自适应律中直接出现，论文未给测速手段或观测器——与本项目"位置+两腔压力可测、速度估计"的合同存在差异（仅识别，不改合同）。

## 1. 模型与控制链（A）

### 1.1 被控对象（3 阶，无阀动态）

    x1dot = x2
    x2dot = x3 - th1*x2 + D1(t)
    x3dot = g1*f(PL,u)*[u - pi(u)] - th2*x2 - th3*x3 + D2(t)
    x = [x1,x2,x3]' = [xp, xpdot, Ap*PL/m]'
    th1=B/m, th2=4*be*Ap^2/(m*Vt), th3=4*be*Ct/Vt,
    g1=4*Ap*be*kt/(m*Vt), D1=d(t)/m, D2=(4*Ap*be/(m*Vt))*q(t),
    f(PL,u)=sqrt(Ps - sign(u)*PL)

- 阶次 3、输入 1（电压 u）；可测信号按 Remark 1：位置 x1 与两腔压力（=> PL => x3=Ap*PL/m）。速度 x2 未说明如何获得。
- 阀动态被显式忽略（"伺服阀带宽远大于液压系统"），**没有第四阶阀状态**；未建模阀动态塞进 D2（式 (2) 的 q(t)）。若真实阀有动态，只能落在 D2 且 |D2dot|<=D2dM 的假设内。
- 匹配/非匹配：D1 在 x2 方程、相对 u 非匹配；D2 在 x3 方程、与 u 同通道，匹配。
- 输入增益 g1*f(PL,u)：g1 有已知区间，f 只给上界 f_max=sqrt(2Ps)，**下界仅文字"far away from zero"，未量化**。
- 死区：x_v = k_i*[u - pi(u)]，pi 为饱和型投影（式 (7)），|pi|<=pi0=max{-bl_min, br_max}；等价于左右斜率相等（m_l=m_r=k_i）的死区。最终控制律中**没有**把 pi 的估计加回去。

### 1.2 从虚拟控制到真实阀输入的链条

    x_d（在线可测，只用原值，不用导数）
      -> z0 = ∫(x1 - x_d)dt  (状态扩张，式 (21))
      -> alpha0 = x_d - k0*z0 - c0*v0^(2p-1)                      (25)
      -> 命令滤波器 F1：w11dot=w12, w12dot=-2*eps*wn*w12-wn^2*(w11-alpha0)  (22)
         x1^c=w11, x1^cdot=w12, 初值 x1^c(0)=alpha0(0), w12(0)=0
      -> alpha1 = x1^cdot - k1*z1 - c1*v1^(2p-1) - z0             (30)
      -> F2（wn=500）-> alpha2 = x2^cdot - k2*z2 + th1hat*x2 - c2*v2^(2p-1) - z1 - D1hat  (34)
      -> F3（wn=1000）-> x3^cdot
      -> u = [ -k3*z3 - z2 + th2hat*x2 + th3hat*x3 - D2hat - c3*v3^(2p-1) + x3^cdot ] / (g1hat*f(PL,u))   (38)
      -> 死区 x_v=k_i[u-pi(u)] -> Q_L=kt*[u-pi(u)]*sqrt(Ps-sign(u)PL) (8) -> PL -> x3

关键点：**x_d 只以未求导形式进入**（z0 的被积函数、alpha0 的加项），这就是"扩张状态消除参考导数"的实际机制；三条虚拟控制所需的导数 x_i^cdot 全部取自滤波器状态 w_{i,2}，不做解析微分。

## 4. 实际优点（可核实）

1. **确实不需要参考的一阶导数**：全文没有任何 x_ddot 出现；x_d 只以原值进入，且 z0 的积分把"跟踪误差的积分"变成可用的辅助状态。对阶跃/方波/锯齿这类参考，这一条在结构上成立，不是口号。
2. **交叉项精确抵消**：th1tilde*x2*v2、th2tilde*x2*v3、th3tilde*x3*v3、g1tilde*f*u*v3、D1tilde*v2、D2tilde*v3 六项被自适应律逐一精确抵消，**分析不需要 x2、x3 的先验有界性**，这比很多液压自适应结果干净。
3. **滤波器补偿进入误差的方式是显式可算的**：xi_i 的动态里放入 (x_{i+1}^c - alpha_i)，它与 zdot_i 中的同一项相消，使 vdot_i 只留 v_{i±1}、-k_i v_i、-c_i v_i^(2p-1) 与 l_i xi_i^(2p-1)。这是命令滤波"补偿"的正确做法。
4. 死区只用界 pi0 与 f_max，不需要死区逆，工程上鲁棒；参数用投影保界，避免估计漂移。

## 5. 适用边界（诚实折中）

1. 结论是实用有限时间 + 残差集，**残差随死区界 D、滤波误差 phi_i、sigma 修正泄漏 sigma1 增大**；"高精度"是仿真数值（8.1e-5 m），不是定理给出的半径。
2. **参考不连续时不能谈"精确跟踪"**：方波跳变处 x1-x_d 必然跳变，定理只保证 v_i/xi_i 的最终界，作者报告的过冲 1.8e-2 是仿真观测。
3. 参数"收敛到真值"只有仿真曲线支撑；sigma 修正确保的只是有界，不是收敛，PE 条件未讨论。
4. 无输入饱和分析；无噪声分析；无采样时间与离散化分析（全文为连续时间设计 + 仿真）。
5. 阀动态被忽略；死区左右斜率相等这一条在真实阀上通常不成立。

## 6. 缺陷与待证清单（编号供 proof_reconstruction 引用）

- D1 式 (36) 首项符号印为正号（应为负），与 (32)(40)(44) 矛盾——排版/OCR 待原图核，数学上必须为负。
- D2 Delta_tilde 的负定系数被多算：可推得 -sigma1/(4mu)*Delta_tilde^2，(44)(46) 却同时用了 -sigma1/(2mu) 与 -sigma1/(4mu)（合计 3/4），theta/g 同理（1/2 + 1/4）。
- D3 **按论文给定 c_i=0.5, l_i=1, p=99/101，有 c_i - l_i/(2p) = -0.0101 < 0**，(47) 的 beta 不能保证非负，(46) 的 -beta*V3^p 项与 (49) 的 ln 都失效。阈值：需 l_i < 2*p*c_i = 0.9802 或 c_i > 0.5101。
- D4 T_c 与 phi_i 无量化式，T1 不可计算；eta 自由，T 依赖 eta 与 V3(0)。
- D5 定理界定 z1=x1-x1^c，不是 x1-x_d；位置误差界需补一步（见复算第 7 节），且被 k0 放大。
- D6 控制增益下界 f_min 未量化；u 隐含在 f(PL,u) 内（f 依赖 sign(u)），分支选择与过零正则性未讨论。
- D7 滤波器状态 w_{i,1}, w_{i,2} 不在 V3 中，其有界性靠 Lemma 4 的 phi 界间接得到；而 alpha_i 含 v^(2p-1)（2p-1=0.96），v 过零时 alphadot 无界，phi 的一致小性未严格建立。
- D8 复现缺口：sigma1、eps（阻尼比）、l0、D1hat(0)、D2hat(0)、theta/g1 区间、死区断点界、扰动界、x(0)、采样时间与求解器均未给。
- D9 引言称"在最终控制律中加入死区补偿项"，与 (38) 的实际结构不符（无补偿项，只有鲁棒阻尼）。

## 8. 与本项目量测合同的差异（只识别，不改合同）

L07 需要 x2 直接进入 alpha2 与四条自适应律；若按本项目用速度估计替代，tau_th1 等四条更新律都会吃到估计噪声，论文对此没有任何分析。位置与两腔压力可测这一条与合同一致（PL 用于 f 与 x3）。若要沿用本方法，速度估计误差必须进入 D1/D2 的界，而不是当作精确量。
